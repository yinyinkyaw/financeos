# Domain Docs

FinanceOS uses a single domain context shared across the web application, server, and API contract package.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant architectural decisions under `docs/adr/` when they exist.
- If either location does not exist, proceed without requiring it to be created first.

## Vocabulary

Use the canonical FinanceOS terms defined in `CONTEXT.md` consistently in tickets, tests, implementation, and documentation. If a required concept has no canonical term, record the ambiguity instead of silently inventing competing terminology.

## Architectural decisions

Surface conflicts with an existing ADR explicitly rather than silently overriding the recorded decision.
