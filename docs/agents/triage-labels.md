# Triage Labels

| Canonical role | FinanceOS state | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Still needs evaluation |
| `needs-info` | `needs-info` | Waiting for a decision or explanation |
| `ready-for-agent` | `needs-agent-help` | Explicitly requested agent assistance |
| `ready-for-human` | `ready-to-build` | Ready for the developer to implement |
| `wontfix` | `wontfix` | Intentionally excluded |

Implementation is human-owned. Never assign `needs-agent-help` automatically.
